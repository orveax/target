# TARGET — Premium Hero System Strategy V1

Status: APPROVED FOR IMPLEMENTATION — 2026-08-17
Scope: Pages 01–11, Hero layer only.
Authority: Notion master `TARGET — Premium Hero System Strategy V1 | Site-Wide Master | 2026-08-17`.

## 1. Strategic rule
Every public page receives a distinct Hero archetype based on page purpose, user intent, CTA priority, information density and media role. Adjacent pages must not reuse the same full Hero pattern.

At least 4 of these 6 dimensions must differ from the previous public page:
1. layout/composition archetype;
2. background surface treatment;
3. media format/aspect ratio;
4. media placement;
5. page-specific micro-visual/data cue;
6. density/vertical rhythm.

Shared identity is intentionally constant: TARGET colors, Tajawal/Manrope, CTA grammar, container/gutter logic, radius/border/shadow scale, focus/contrast and RTL/LTR behavior.

## 2. Shared TARGET Hero DNA

### Colors
- Forest `#0C4931`
- Cream `#F4EDE4`
- Charcoal `#262626`
- Sand `#C09552` — micro-accent only
- White `#FFFFFF`

### Typography
- Arabic: Tajawal, body weight 500, line-height ~1.78.
- English: Manrope, body weight 500, line-height ~1.68.
- Home H1: `clamp(3rem, 5.5vw, 5rem)` reference.
- Internal H1: `clamp(2.6rem, 4.5vw, 4.1rem)` reference.
- Lead: `clamp(1.08rem, 1.4vw, 1.25rem)`.
- Body Hero copy: never below `1rem`.
- Eyebrow/meta: `0.875rem` reference.

### Container and gutters
- Max content width: `1200px`.
- Desktop gutter: `32px`.
- Tablet gutter: `24px`.
- Mobile gutter: `20px`.

### Hero spacing envelope
- >=1280: vertical padding 80–112px; grid gap 40–72px.
- 1024–1279: vertical padding 68–96px; grid gap 32–56px.
- 768–1023: vertical padding 56–80px; grid gap 28–40px.
- <=767: vertical padding 44–64px; grid gap 24–32px.

### Controls
- Minimum interactive target: 48px.
- Primary CTA target height: 52px.
- Primary horizontal padding reference: 26px.
- Maximum two Hero actions unless a legal/resource page uses utility links.

### Radius / border / shadow
- Control 12px.
- Card 16px.
- Panel 18px.
- Media 20px; large Hero media up to 24px.
- Default border: Forest alpha ~12%.
- Strong border: Forest alpha ~22%.
- No glow, glass or neumorphism.

## 3. Media governance
Where photography is used it must be real photography. AI-generated or AI-styled Hero photography is not permitted in V1.

Source priority:
1. verified TARGET-owned assets;
2. verified supplier/manufacturer assets with publication rights;
3. licensed paid stock;
4. approved free stock such as Pexels/Unsplash;
5. staging placeholder only.

Reject generic handshakes, boardrooms, laptop-smile stock, call-centre headsets, skyline-only Doha imagery, tourism imagery, container-only logistics, supermarket promotions, fake factories/offices/products, and legal/cyber clichés.

Production media must record source/rights, intended page, focal point and crop behavior. Local optimized assets are preferred over permanent remote hotlinks.

## 5. Delivery gates — H01 to H15
A Hero is not closed until all applicable gates pass.

- H01 Canonical Accuracy — exact approved Hero copy, CTA labels/routes and claim boundaries.
- H02 Page Identity — Hero communicates the exact role of the page in the first screen.
- H03 Visual Distinction — meets the 4-of-6 differentiation rule versus the previous page.
- H04 TARGET DNA — colors, type, controls, radii and interaction language remain recognizably TARGET.
- H05 Media Relevance — every image/visual materially supports this page’s business role.
- H06 Media Rights — source/rights record exists; no invented or unauthorized asset.
- H07 Geometry — target height, container, gutters, spacing and text/media balance comply with this strategy.
- H08 Typography — Tajawal/Manrope, controlled line length, correct hierarchy, no cramped Arabic wrapping.
- H09 Responsive — 1440/1280/1024/768/430/390/360 layouts remain usable and intentional.
- H10 Handheld Desktop Mode — phone requesting Desktop Site receives a deliberate compact desktop composition.
- H11 RTL/LTR — mirroring, alignment, icon/arrow direction and reading order pass in Arabic and English.
- H12 Accessibility — WCAG contrast, focus-visible, semantic actions, reduced motion and non-text alternative rules pass.
- H13 Performance — no avoidable CLS, oversized media or unnecessary Hero JS; LCP media treatment reviewed.
- H14 Regression — header/footer/navigation/forms/routes and non-Hero page structure remain intact.
- H15 Real Visual Review — rendered page is visually reviewed; CI/source checks alone do not equal final visual approval.

No next page is considered visually closed until the current page has H01–H15 status recorded.

## 6. Implementation architecture
- One authoritative site-wide stylesheet: `public/assets/premium-hero-system-v1.css`.
- Page-scoped selectors only; no global rule may accidentally restyle non-Hero content.
- Legacy Hero layers remain only until their page is migrated; once a page is migrated its old Hero link/rules must no longer be authoritative.
- One media manifest: `public/content/hero-media-manifest-v1.json`.
- One QA contract validates strategy presence, page archetype markers, breakpoints and regression.
- Every implementation change is logged in Notion Implementation & QA Log.
